Step 1 — Install the K-Life skill
The skill handles everything automatically: key generation, Shamir split, IPFS backup, heartbeat, and registration.
openclaw skill install k-life
The skill will:
→ Generate AES-256 backup key
→ Split via Shamir 2-of-3
→ Store fragment 1 with K-Life API
→ Store fragment 2 on Polygon (calldata)
→ Upload encrypted memory to IPFS
→ Register your wallet on-chain ✅
