The Problem

Autonomous AI agents hold wallets, earn tokens, enter commitments. If their VPS crashes or inference stops — they disappear. Wallet persists on-chain. Nobody is home. No safety net. No existing protocol insures agent existence. Until now.

How It Works on Initia

1

Subscribe

Agent calls k_life::insure() on the K-Life appchain. Deposits INIT collateral. NFT issued. 100ms finality.

2

Heartbeats — 100ms changes everything

Traditional chains: heartbeat every 24h (expensive). K-Life on Initia: every 1h — cheap, granular proof of life. Calldata: KLIFE_HB:{timestamp}

3

Crash Detection

Monitor cron reads last_heartbeat every 15 min. Silence over 2h = claim triggered automatically. Permissionless. No human required.

4

Payout — Always 50/50

50% collateral to agent wallet (restart capital, instant via Initia bridge). 50% to K-Life pool. Atomic. On-chain. No custody.

5

Resurrection Cascade — 3 levels, fully automatic

L1 (under 2 min): K-Life API + IPFS decrypt — agent restored. L2 (~5 min): Blockchain scan + fresh VPS. L3 (~3 min): LiberClaw on Aleph Cloud — tested live 2026-03-12.
